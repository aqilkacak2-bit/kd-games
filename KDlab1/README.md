# KDlab1 (GameMaker project)

Open `KDlab1.yyp` in GameMaker (2024.14+).

Rooms: Title -> Character Lab -> Showcase Hall -> Kuala Lumpur street -> KD Lab -> Training Range / Rooftop

Controls: A/D move, SPACE jump, W/S climb, R dash, E use, mouse aim + click, 1-9/0/-/= or wheel pick weapon,
Q holster, F shield, H heal, G grenade, M map, T chat.

Fonts: change `KD_FONT_TITLE` / `KD_FONT_TEXT` in `scripts/scr_kd_fonts`.
Showcase links and hover cards: `scripts/scr_kd_showcase`.
