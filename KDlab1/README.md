# KDlab1 (GameMaker project)

Open `KD_cs2.yyp` in GameMaker (2024.14+).

Rooms: Title -> KD Lobby -> Character Lab -> Showcase Hall -> Kuala Lumpur street -> KD Lab -> Training Range / Rooftop -> Neon Dungeon

Controls: A/D move, SPACE jump (hold in the air for the jetpack once unlocked), W/S climb, R dash, E use,
mouse aim + click, 1-9/0/-/= or wheel pick weapon, Q holster, F shield, H heal, G grenade, M map, K skill tree, T chat.

Fonts: change `KD_FONT_TITLE` / `KD_FONT_TEXT` in `scripts/scr_kd_fonts`.
Showcase links and hover cards: `scripts/scr_kd_showcase`.
Skill tree and trails: `scripts/scr_kd_skills`. Neon Dungeon run: `scripts/scr_kd_run`. Pet Bay and Item Shop: `scripts/scr_kd_shop`.
